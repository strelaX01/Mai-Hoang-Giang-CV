# 🧾 React CV Website

A simple and responsive **CV Website** built with **ReactJS**.  
This project was created as part of a Frontend Developer test assignment.

---

## 🚀 Features
- Modern two-column CV layout  
- Popup gallery for Degree, Transcript, and Certificates  
- Fully responsive design  
- Clean and modular component structure  
- Built using React + Lucide React icons  

---

## 🛠️ Tech Stack
- **ReactJS** (create-react-app)
- **Lucide React** – for modern icons  
- **CSS3** – for styling  
- **JavaScript (ES6)**  

---
